# fxricky's nvim

My personal Neovim config, built on [LazyVim](https://github.com/LazyVim/LazyVim).

Yes, I switched the colorscheme to Gruvbox. No, I will not be going back.

## The vibe

- **Theme:** Gruvbox (dark, obviously)
- **Status line:** lualine, with a smiley that judges your commits
- **Tabs:** bufferline, because tabs are life
- **Find & replace:** grug-far, for when sed gets scary
- **Diagnostics:** trouble, so my errors have a home
- **Session restore:** persistence, because context switching is for the weak

## Keys I actually remember

- `<leader>` is space, because it always was
- `<leader>fp` opens the plugin file browser (my editor is a self-reference loop)
- `<leader>co` / `<leader>cR` organize & rename your TypeScript, no questions asked

## Extras

TypeScript, JSON, and Python tooling via LazyVim extras — batteries included,
but only the ones I charge with.

## Usage

Open Neovim. It handles the rest.
